# Linux Commands for Cloud Engineers

## 1. `pwd`

Shows the current folder location.

```bash
pwd
```

## 2. `ls`

Lists files and folders in the current directory.

```bash
ls
```

## 3. `ls -la`

Lists all files, including hidden files, with detailed information.

```bash
ls -la
```

## 4. `cd`

Moves into a folder.

```bash
cd Desktop
```

## 5. `cd ..`

Moves one folder back.

```bash
cd ..
```

## 6. `mkdir`

Creates a new folder.

```bash
mkdir my-folder
```

## 7. `touch`

Creates a new empty file.

```bash
touch file.txt
```

## 8. `cat`

Displays the content of a file.

```bash
cat file.txt
```

## 9. `nano`

Opens a simple terminal text editor.

```bash
nano file.txt
```

## 10. `clear`

Clears the terminal screen.

```bash
clear
```

## 11. `rm`

Deletes a file.

```bash
rm file.txt
```

## 12. `rm -r`

Deletes a folder and its contents.

```bash
rm -r my-folder
```

## 13. `cp`

Copies a file.

```bash
cp old.txt new.txt
```

## 14. `mv`

Moves or renames a file.

```bash
mv old.txt new.txt
```

## 15. `chmod`

Changes file permissions. (Read/Write)

```bash
chmod 600 key.pem
```

## 16. `whoami`

Shows the current logged-in user.

```bash
whoami
```

## 17. `date`

Shows the current system date and time.

```bash
date
```

## 18. `df -h`

Shows disk space usage in a readable format.

```bash
df -h
```

## 19. `top`

Shows running processes and system resource usage.

```bash
top
```

## 20. `ps`

Shows running processes.

```bash
ps
```

## 21. `curl`

Makes a request to a URL or API.

```bash
curl https://example.com
```

## 22. `ping`

Tests network connectivity to a server.

```bash
ping google.com
```

## 23. `ssh`

Connects to a remote server securely.

```bash
ssh username@server-ip
```

## 24. `history`

Shows previously used commands.

```bash
history
```

## 25. `man`

Shows the manual/help page for a command.

```bash
man ls
```
