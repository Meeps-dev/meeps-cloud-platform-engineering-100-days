# Day 1 Notes: Understanding Cloud and Platform Engineering

- I now understand that cloud engineering is about running applications, databases, storage, networking, and security using cloud services instead of physical servers.

- Cloud helps companies move faster because servers and services can be created in minutes instead of waiting for hardware setup.

- Cloud also helps companies scale their systems when traffic grows and reduce resources when traffic drops.

- Platform engineering is about building internal tools, templates, and systems that help developers deploy and manage applications easily.

- A cloud engineer mainly focuses on cloud infrastructure like AWS services, networking, security, and servers.

- A platform engineer focuses on making developers more productive by creating reusable deployment systems and self-service infrastructure.

- I now understand that infrastructure means all the things needed to run an application properly, such as servers, databases, storage, DNS, firewalls, monitoring, and CI/CD pipelines.

- The main lesson is that cloud and platform engineering are not just about knowing AWS services. They are about understanding infrastructure problems and choosing the right tools to solve them.
